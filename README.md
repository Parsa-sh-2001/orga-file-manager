# orga-file-manager
A simple file manager; in python!

# How it works
**simply!**
Using the *Json, OS and Shutil libraries* along with *A customtkinter GUI*, You are Able to make A simple file manager like so.

# How to run it
Firstly:
  - **Windows ONLY**
  - The Application **Can not be run in A Python terminal**
  -  It shall be run in An application terminal **Such as *Visual studio code****
  - Libraries **Customtkinter** shall be installed
On visual studio code; Find the file *cfirsttime.py*; and run the file everytime you'd like to start the Application. 

# Startup
firstly; using The JSON file *joined.json*; The **OS library** will automatically create A desktop file called *Files*
Inside this file; the folders listed will be Added; Again with the JSON:

 - **Codes**
 - **Disc images**
 - **Documents**
 - **Exe**
 - **Images**
 - **Scientific Files**
 - **Videos**
 - **Other**

and each folder contains a **txt** File; That lists All the supported extentions.

# After startup?
**The *cfirsttime* file will launch the main file**, through which You can select files with the Button; and send it with the button on the bottom.

# What if I rejoin?
Dont worry! when you run cfirsttime.py; You will get put back into the main application; As the *joined.json* which discussed earlier has changed data.
